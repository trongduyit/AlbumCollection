## 🌐 Custom Domain (Optional)

To use your own domain:

1. **Domain Setup:**
   - Point domain nameservers to Cloudflare
   - Or configure A/CNAME records

2. **GitHub Pages:**
   - Settings → Pages → Custom domain
   - Enter your domain

3. **GitHub will:**
   - Auto-generate CNAME file
   - Create SSL certificate
   - Redirect traffic

## 🔐 Cloudflare Tunnel (Optional)

## 📞 Support & Maintenance

### Common Tasks

**Update photos:**
- Add to `assets/images/`
- Push to GitHub
- Auto-deploys!

**Change music:**
- Replace `assets/music/music.mp3`
- Push to GitHub
- Live in 2-3 minutes

**Customize colors/design:**
- Edit `index.html`
- CSS within `<style>` tag
- Push to GitHub
- Auto-deploys!

### Troubleshooting

| Issue | Solution |
|-------|----------|
| Website not updating | Wait 2-3 minutes, check GitHub Actions |
| Photos not showing | Verify files in assets/images/ exist |
| Music not playing | Check assets/music/music.mp3 exists |
| 404 errors | Check file paths are relative |
